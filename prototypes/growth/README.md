# 成长档案中心交互原型

方案一，P0包含身高、体重、头围及身高测量方法。管理员可编辑/删除所有记录，普通成员仅本人，只读成员不可新增或修改。

覆盖：三指标切换、真实日期间距曲线和点选、时间范围、测量历史按月折叠、里程碑/学习、详情、新增、编辑删除、宝宝切换与空状态。顶部可模拟角色；爸爸记录用于验证他人记录权限。数据仅保存在内存。

此版为首轮核心流程原型：已支持成长事件选择照片与视频（混合合计最多10个）、缩略图与大图预览、视频播放、移除、编辑保留和保存后列表/详情展示；文件仅通过本机临时链接预览，不会真实上传。未接入云端媒体存储、分页后端、标准参考曲线或云端。曲线仅家庭实际数据。管理员对应当前owner角色。身高填写时必须选择卧位身长/站立身高；头围使用软尺测量，未提供专业判断。

脚本语法和模拟DOM交互检查通过（上限、超额提示、移除补选、预览、保存、取消编辑保留、只读权限）；浏览器视觉、触摸、弹窗焦点验收受工具限制尚未完成。后续需补足真实云端上传、失败重试与返回滚动/折叠状态保留，再进入生产实现。

## 卫健委标准参考版

生长曲线已接入官方《7岁以下儿童生长标准》（WS/T 423—2022）附录A原始表值，支持参考线开关、3/7条参考线、测量点百分位区间对照与标准原文查看。头围范围单独限制为0～3岁；不输出诊断或精确插值百分位。详见 [reference-design.md](reference-design.md)。

检查：`node prototypes/growth/verify-prototype.cjs`。生产接入前仍需原表双人复核和专业评审。
