# 今日照护 · 三套独立 HTML 原型

打开 index.html 选择方案，或直接打开 option-1.html、option-2.html、option-3.html。每个方案自带样式、脚本和示例数据，无网络依赖。

- 方案一：统一记录簿 → 按日期折叠分组 → 单条详情。多日默认展开最近一个有记录的日期，支持全部展开/收起；返回保留分组状态、筛选和滚动位置。
- 方案二：照护日志原地展开，一次展开一条。
- 方案三：照护概览 → 分类专页 / 当天记录 → 单条详情。

均支持日期范围、喂养子类型筛选、模拟首页入口、新增演示记录及空结果反馈。记录只保存在页面内存，刷新重置。健康新增仅演示体温；睡眠新增仅演示同日区间。示例日期固定为2026-10-20，避免原型随访问日期变化。

实际小程序的 src、cloud、构建配置和数据库没有因本次原型制作而修改。

## 验收

脚本语法和使用模拟DOM的核心交互逻辑已检查。当前没有可用浏览器自动化工具，真实渲染、触摸、弹窗焦点及小屏布局的视觉验收尚未完成，不能视为已通过视觉验收。
