# 家庭关联交互原型

打开 `index.html` 即可使用，无依赖、无需连接云环境。样式复用 `../growth/base.css`，请保持目录结构。

- 侧栏切换：游客、待审批、创建者、管理员、普通、只读。
- 游客：建立个人宝宝档案 → 关联家庭 → 创建，或输入 `HOME26` 加入。
- 待审批：用“模拟审批通过/被拒绝”体验结果；实际产品没有模拟按钮。
- 创建者：家庭 → 申请管理/成员详情 → 调整权限、移除；设置 → 转让创建者。
- 普通成员：身份 → 修改称谓或申请变更；成长 → 仅管理本人记录。
- 本地 localStorage 保存演示状态；侧栏重置或切换场景可恢复数据。
- 验证：`node prototypes/family/verify.cjs`。

PRD：`../../design-docs/family-association-prd.md`。

此为流程原型，不代表真实鉴权；没有连接真实数据，不用于生产。当前环境无法调用浏览器控制工具，视觉和触控验收尚未完成。
